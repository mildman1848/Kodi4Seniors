# Fernbedienung und Navigation

## Zielgerät

Primäres Zielgerät ist ein Fire TV mit Kodi. Die Bedienung erfolgt über eine normale TV-Fernbedienung per HDMI-CEC oder über die Fire-TV-Fernbedienung.

## Vorausgesetzte Tasten

| Taste                          | Funktion                                                   |
| ------------------------------ | ---------------------------------------------------------- |
| Pfeil hoch/runter/links/rechts | Zwischen großen Kacheln und Listen wechseln                |
| OK                             | Ausgewählten Bereich öffnen                                |
| Zurück                         | Eine Ebene zurück                                          |
| Home                           | Zur Startseite oder Fire-TV-Startseite, abhängig vom Gerät |
| Power                          | Gerät/TV ausschalten, abhängig von CEC-Konfiguration       |
| Lautstärke                     | TV/Receiver-Lautstärke                                     |

## Designregeln

- Jede wichtige Aktion muss mit Pfeiltasten und OK erreichbar sein.
- Keine Pflicht für Tastatur, Maus oder Touch.
- Der Fokus muss jederzeit sichtbar sein.
- Listen dürfen nicht die primäre Alltagsnavigation sein.
- Zurück darf nicht in komplexe Kodi-Menüs führen, wenn ein einfacher Rückweg zur Startseite sinnvoller ist.

## Abnahme-Test

Vor Übergabe an den Haushalt:

1. Kodi startet direkt in Kodi4Seniors.
2. Nach dem Start ist eine Hauptkachel fokussiert.
3. Pfeile wechseln nachvollziehbar zwischen den vier Hauptbereichen.
4. OK auf Live TV öffnet TV/EPG oder führt zur PVR-Einrichtung.
5. OK auf Mediatheken öffnet den Mediatheken-Hub.
6. ARD und ZDF lassen sich mit Pfeilen + OK öffnen.
7. Zurück führt aus Hub/Bibliothek wieder verständlich zurück.
8. Technik-/Einstellungen sind nicht versehentlich erreichbar.
