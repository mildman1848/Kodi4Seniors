# Roadmap

## Phase 1 — Fundament stabilisieren

Status: in Arbeit.

- README und README.DE als echte Projekt-Einstiege ausbauen
- Produktvision dokumentieren
- Setup-Playbook für Fire TV, HDMI-CEC und Betreuerbetrieb erweitern
- Recovery-Doku ergänzen
- Fernbedienungs-/Navigationsmatrix ergänzen
- Portable Repo-Validierung ohne lokale `xmllint`-Pflicht einführen
- Alle Skin-XML-Dateien validieren
- Versionskonsistenz zwischen `addon.xml`, `package.json` und `VERSION` prüfen
- Release-ZIP-Inhalt prüfen

## Phase 2 — Alltagsoberfläche schärfen

- Technik-/Einstellungen-Kachel im Alltag weniger prominent machen
- Fokuszustände stärker und einheitlicher hervorheben
- Texte konsequent deutsch und englisch pflegen
- DialogButtonMenu vereinfachen
- Fire-TV-/CEC-Navigation testen und dokumentieren

## Phase 3 — Betreuungsmodus ausbauen

- Betreuungsmenü strukturieren: Live-TV, Mediatheken, Bibliothek, Add-ons, System
- Standard-PIN-Hinweis sauber formulieren
- Technikmodus-Zustand sichtbar machen
- Optional Timeout für Technikmodus prüfen

## Phase 4 — Mediatheken-Hub v2

- ARD und ZDF als bevorzugte, klare Einstiege
- Fehlende Add-ons freundlich erklären
- Optional installierte Add-ons markieren
- Keine direkte Überforderung durch rohe Kodi-Addon-Listen im Alltag

## Phase 5 — Releasefähig als Komplettpaket

- Screenshots aktualisieren
- Release-ZIP und GitHub Release automatisieren
- Publishing in das Kodi-Repository unter `mildman1848.github.io` verifizieren
- Codeberg-Mirror nach jedem Release prüfen
