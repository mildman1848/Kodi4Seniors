# Kodi4Seniors

English: [README.md](README.md)

Seniorenfreundlicher Kodi-Skin mit großen Einstiegen, vereinfachter Navigation und einem Setup,
das auf einmalige technische Einrichtung und einfache Alltagsnutzung ausgerichtet ist.

## Repository-Struktur

- `skin.kodi4seniors/`: installierbarer Kodi-Skin
- `skin.kodi4seniors/1080i/`: Skin-Fenster und Include-Definitionen
- `scripts/build_release.py`: baut das Release-ZIP
- `scripts/publish_to_repo.py`: publiziert den Skin nach `mildman1848.github.io`
- `docs/setup-playbook.md`: Einrichtungs-Checkliste

## Lokale Validierung

```bash
npm run validate
```
