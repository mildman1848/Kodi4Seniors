# Kodi4Seniors

Deutsch: [README.DE.md](README.DE.md)

Senior-friendly Kodi skin with large entry points, simplified navigation, and a setup model aimed
at one-time technical installation plus easy daily use.

## Repository Structure

- `skin.kodi4seniors/`: installable Kodi skin payload
- `skin.kodi4seniors/1080i/`: skin windows and include definitions
- `scripts/build_release.py`: builds the release ZIP
- `scripts/publish_to_repo.py`: publishes the skin to `mildman1848.github.io`
- `docs/setup-playbook.md`: setup checklist for the installer

## Local Validation

```bash
npm run validate
```
