# Contributing to Kodi4Seniors

English: [CONTRIBUTING.md](CONTRIBUTING.md)

## Vor einem Pull Request

- Änderungen sollten auf den Skin oder dessen Release-Automatisierung fokussiert bleiben.
- Verweise auf passende Issues ergaenzen, wenn vorhanden.
- README, Changelog oder Setup-Doku aktualisieren, wenn sich Verhalten ändert.
